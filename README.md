# Portfolio de Miler Castro

Portfolio profesional enfocado en implementación de software, análisis
funcional, QA y desarrollo backend.

## Tecnologías

- Next.js 16 con App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React y React Icons

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Para probar desde otro dispositivo de la misma red:

```bash
npm run dev -- --hostname 0.0.0.0
```

## Validación

```bash
npm run lint
npm run build
```
